Mayhem Companion 0.6.0 stops leftover build files from other tools opening ahead of your imported builds, turns each build page into a buy order with components and a starting purchase, and shows champion challenges on your pick and bench in champion select.

## What's new

- **Imported builds are no longer hidden behind another tool's leftover.** Some tools (Blitz, for one) don't use the client's item sets: they drop a file into the game's `Config` folder, and the game opens it ahead of every item set, for every champion, until something deletes it. With **Replace other tools' builds** on, the app now removes recognised tool files from `Config\Global\Recommended` and from your current champion's `Config\Champions\<name>\Recommended` when it imports a build. The client's own files, anything without a tool's name on it, Summoner's Rift-only files and other champions' folders are left alone.
- **Buy order with components.** Each `[Mayhem]` page now lists the full build as numbered steps, one row per item: its components, dearest first, then the finished item, with the item's name and price in the row title. Boots are moved to second. These rows replace the old single "Full build" row.
- **Start row.** Each page opens with what your starting gold buys towards the first item: the dearest component that fits (breaking down the ones that don't), basic Boots if 300g is left, and a Refillable Potion if 150g is spare. The row title shows how much of the gold is spent.
- **Champion challenges in champion select.** Your pick and each bench champion carry a row of dots under the name, one per challenge that counts champions one by one and applies to that champion (an S- in ARAM, the mastery challenges, the class mastery ones). A dot is filled when that challenge is already done on that champion. Hover the champion for what is still to do and what is done, with progress to the next level. Turn it off with **Show champion challenges on my pick and bench in champion select** in Settings.

## Install or upgrade

Versions from 0.4.0 download this update automatically; choose **Quit** from the tray menu and open the app again to install it. Otherwise download `mayhem-companion.exe`, put it in a writable folder of its own, and run it. Your existing settings are retained and new settings get their defaults. Set League to **Borderless** or **Windowed** for the overlay.

## Validation

- Portable logic tests and the full Windows test suite pass, including new tests for which tool files are removed and kept, the buy order and Start row, and which challenges apply to a champion.
- The buy order and Start row were checked against real build data for eight champions, and the challenge dots against a saved challenge snapshot.
- None of this release has been checked in a live game or in the companion window yet. See the notes below.

## Notes

- The buy order is worked out from item recipes, not from purchase statistics: the data has no component order or boots timing, so "dearest component first" and "boots second" are rules of thumb.
- Starting gold is assumed to be 1400, the standard ARAM amount. If Mayhem differs, set `starting_gold` in `config.json`.
- The Start row takes the biggest single component that fits, which is not always the combination that spends the most gold.
- With **All builds on one page**, every build style gets its own Start and buy rows, so that page is considerably longer than before.
- If another tool is still running during your games it may write its build file again after the import; the app removes it at the next import.
- The champion-challenge dots and their hover text have not been seen on screen. On bench rows the details are added to the existing team-fit tooltip, which makes it long.
- The dots include the Legacy mastery challenges. Challenge progress needs the League client open and can lag by up to ten minutes after a game.
- The executable is unsigned. Windows SmartScreen may warn about it; a SHA-256 checksum is included with the download.
